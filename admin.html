Panel de administración

Acceso

Prototipo: para entrar hace falta un token de acceso de GitHub del repositorio. No está guardado en ningún archivo: se pega aquí y solo se mantiene mientras esta pestaña esté abierta.

Permiso necesario: Contents: Read and write, solo para este repositorio.

Productos

Cambia el precio o la disponibilidad, o borra un producto. Los cambios no se aplican hasta que pulses «Guardar cambios en GitHub».

Añadir un producto nuevo

Las fotos hay que subirlas antes a la carpeta img/productos/ del repositorio. Aquí solo se escribe su ruta.

Si no pones foto, el producto saldrá con un recuadro provisional.

Pedidos

Importante: aquí solo aparecen los pedidos hechos desde este mismo navegador (por ejemplo, los de prueba del equipo). Los pedidos de otras personas no llegan al panel, porque la web no tiene servidor.

Todavía no hay pedidos en este navegador.
